System Architecture

Clean Separation of Layers

Everything is split into three clean files with zero external build dependencies:

devpost-hackathon-project/
├── index.html            # Layout, SVGs (desk, drawer, laptop), modals (to-do, journal, breathe)
├── style.css             # Dark Dome palette, camera transforms, tilted frames, gloomy filters
├── game.js               # Central state machine (gameState), event listeners, timers
└── devpost/              # Planning documentation (scope, prd, spec) and HTML companions
